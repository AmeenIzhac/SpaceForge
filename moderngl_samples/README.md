# moderngl samples — dense open plane with buildings

Generated by `plane_city.py` (scene spec) and rendered by `plane_gl.py`
(native OpenGL, offscreen framebuffer -> ffmpeg). Same spec format as the
training scenes, so the bearing ground truth is computed identically.

Each scene: ~55 objects — 10-16 buildings (5-14 wide, 7-34 tall, placed
22-75 units out), 10-16 mid-size props (2.5-7 tall), and 22-34 small objects
(0.5-1.4) scattered near the walked path.

Cost, measured on these six: **1809 frames in 10.1 s = 180 fps, 1.68 s per
scene**, single process. Four processes would put it near 0.5 s/scene.
For comparison the same-length scenes with ~5 objects run 1.3 s, and the
three.js renderer runs ~23 s.
